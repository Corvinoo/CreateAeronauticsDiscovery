This mod is an extension of the Create Aeronautics and will procedurally generate airships, dynamic flying events, and a new sky trader mob! **You can even add your own structures and custom events!**

**Available on:**

**Modrinth:** https://modrinth.com/mod/create-aeronautics-discovery

**Curseforge:** https://www.curseforge.com/minecraft/mc-mods/create-aeronautics-discovery

### Commands (OP)

`/spawnprefab [pos] [structure]` Spawn any NBT prefab as a physics-enabled airship

`/discovery flyover toggle` Toggle automatic flying events

`/discovery flyover` Triggers a flying event manually

`/discovery cleanchildsl` Removes all stray barrels originating from flyovers from the world.

You can locate any mod's world generated structure (such as the hot hair balloon) by using the vanila command `/locate structure aeronauticsdiscovery:[namestructure]`

### Configurations

You can configure:

*   Lifetime flying events
*   Frequency flying events
*   Size area reserved to 1 flyover spawn at the time
*   Max Travel distance of flyover before depsawn
*   Obstacle Avoidance: Toggle whether flyovers check for clear paths before spawning
