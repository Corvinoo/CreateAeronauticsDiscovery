This project is licensed under All Rights Reserved, but all kinds of contributions are welcome!
If you have ideas or assets for the mod you'd like to share, you can open an issue on the [github tracker](https://github.com/Corvinoo/CreateAeronauticsDiscovery/issues) or join the [Discord Server](https://discord.gg/dXYHjHvvem)!

PRs for fixes or progress on already planned features are also gladly accepted.
It's helpful if the git history is kept clean and linear, simple [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/) are appreciated.

One important note about code contributions: I take a lot of care into ensuring the quality of this project and I ask contributors to please do the same.
So please always make sure that:
- You understand every change of your submission
- You have personally tested and verified the affected functionalities

To ensure this, pull requests submitted by AI agents will not be merged.

Thank you for reading this and thanks to anyone interested in contributing!
